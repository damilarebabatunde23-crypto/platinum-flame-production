# Platinum Flame Production — Studio Web Platform
> **“Igniting Cinema. From Spark to Screen.”**

A tier-one cinematic web application built for **Platinum Flame Production**, matching top Hollywood studio prestige (Skydance, Warner Bros., Legendary Pictures, A24 luxury tier).

## 🎧 Cinematic Audio Feature
Click the **SOUND** button in the top navigation bar to toggle a synthetic warm Hollywood theatrical sub-bass soundscape (built with Web Audio API, no external audio file required).
